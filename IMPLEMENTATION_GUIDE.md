## Form Data Persistence (Session Handling - Additional Feature)

### Problem
When user fills upload form and refreshes ? data is lost.

### Solution (Frontend)

**1. Save to localStorage as user types:**
```javascript
const FormComponent = () => {
  const [formData, setFormData] = useState(() => {
    // Load from localStorage on mount
    const saved = localStorage.getItem('thesisUploadDraft');
    return saved ? JSON.parse(saved) : initialState;
  });

  const handleChange = (e) => {
    const updated = { ...formData, [e.target.name]: e.target.value };
    setFormData(updated);
    // Save to localStorage on every change
    localStorage.setItem('thesisUploadDraft', JSON.stringify(updated));
  };

  const handleSubmit = () => {
    // Send to backend
    // On success, clear draft
    localStorage.removeItem('thesisUploadDraft');
  };

  return (
    <form>
      <input
        name="title"
        value={formData.title}
        onChange={handleChange}
      />
      {/* ... other fields ... */}
    </form>
  );
};
```

**2. Optional: Save draft to backend**
```javascript
// Create endpoint: POST /api/thesis/draft
// User can continue editing later from another device
```
